# TX-set_RF2

[English README](README.md)

EdgeTX（カラー液晶機）用ウィジェットです。フライトモード（FM0〜FM2）ごとの **スロットル回転数（Thr RPM）** と **コレクティブピッチ（Coll P.）** をメイン画面で確認し、音声で読み上げながらその場で調整できます。
Rotorflight を使うRCヘリ向けで、今後 **Rotorflight 4.7 のマスターゲイン調整** に対応する予定です（[ロードマップ](#ロードマップ)参照）。

> 以前作成した `TX-Set2`（VBar NEO向け）を元にしています。本バージョンでは Tail Gyro 機能を削除しました。

## 機能

- FM0／FM1／FM2 の Thr RPM と Coll P. を並べて表示し、現在のFMを強調表示
- 編集スイッチが EDIT 側のとき、2つの入力チャンネル（CH13 / CH11）で値を増減
- 編集スイッチによる EDIT / LOCK 切り替え（飛行中の誤操作防止）
- 変更後に値を音声で読み上げ（遅延・ガード時間を設定可能）
- ウィジェットの高さに応じてレイアウトとフォントサイズを自動調整

| 行 | グローバル変数 | 入力チャンネル | 表示 |
|---|---|---|---|
| ThrRPM | GV1 | CH13 | 回転数（10rpm単位で切り捨て） |
| Coll P | GV2 | CH11 | 角度（0〜MaxColl） |

1回の操作で、**現在のフライトモード**のGVが ±1 変化します。GVは -100〜+100 に制限されます。

- `ThrRPM = floor(MaxRPM × (GV + 100) / 2000) × 10`（GV -100 → 0、GV +100 → MaxRPM）
- `Coll   = MaxColl × (GV + 100) / 200`（GV -100 → 0°、GV +100 → MaxColl°）

## 動作要件

- EdgeTX **2.12**（開発・動作確認バージョン）のカラー液晶搭載送信機
- GV1・GV2 をモデル内で使用していること（フライトモードごとに独立した値にしておく）
- 「増/減」の操作で ±50% 以上に振れるチャンネル2本（CH13、CH11）。モメンタリースイッチやトリムボタンをミキサー経由で割り当てる想定です。ウィジェットは `|値| > 500`（±1024 = ±100%）を検出して1回分の操作と判断します

## インストール

1. `WIDGETS/TXsetRF2` フォルダを、送信機のSDカードの `/WIDGETS/` にコピーします。
   - EdgeTX の制限でフォルダ名は **8文字以内** にする必要があるため `TXsetRF2` としています。ウィジェット一覧には `TX-set_RF2` と表示されます。
2. 送信機を再起動（またはモデルを再選択）します。
3. メイン画面にウィジェットを追加します：*画面設定 → ゾーンを選択 → ウィジェット → TX-set_RF2*
4. ウィジェット設定を開き、**EditSwitch** のソースを選びます。

## 使い方

1. 編集スイッチを EDIT 側（値 > 500）にします。現在のFMのヘッダーがアクティブ色に変わります。
2. CH13（Thr RPM）または CH11（Coll P.）を操作します。現在のFMの値が1ステップ変わり、音声で読み上げられます。
3. 編集スイッチを LOCK 側に戻すと、それ以上変更されません。

## ウィジェットオプション

| オプション | 初期値 | 説明 |
|---|---|---|
| EditSwitch | – | 編集を有効にするソース（値 > 500 で EDIT） |
| ColorPast | グレー | 非アクティブFM列／LOCK時の色 |
| ColorActive | 赤 | EDIT時の現在FMヘッダーの色 |
| ColorLabel | 白 | ラベルと現在FMの値の色 |
| MaxColl | 14 | GV = +100 のときのコレクティブピッチ（10〜16） |
| MaxRPM | 3000 | GV = +100 のときのスロットル回転数（2000〜8000） |
| VoiceDelay | 40 | 変更後、読み上げるまでの待ち時間（×10ms、0〜200） |
| VoiceGuardTime | 70 | 読み上げ同士の最小間隔（×10ms、0〜300） |

音声：Thr RPM は回転数の数値、Coll P. は 0.1° 単位の数値（例：123 = 12.3°）で読み上げます。
